# 柜满载

面向外贸纸箱装柜的离线计算工具。直接打开 `index.html` 即可使用，不需要安装 Node.js、npm 或其他运行环境。

## 当前能力

- 支持 20GP、40GP、40HQ、45HQ 和自定义柜内尺寸。
- 支持多项货物混装，录入纸箱长、宽、高、单件重量和数量。
- 支持可全向翻转、只可水平旋转、不可旋转。
- 支持允许或禁止向上叠放。
- 按柜内净空和最大载重计算，输出建议柜数、每柜装载件数、体积、重量和利用率。
- 提供可旋转、缩放和切换正视图/俯视图的柜内摆放示意。
- 支持打印报告和导出 CSV 装柜清单。
- 支持复制方案链接，打开链接即可恢复柜型和货物数据。
- 部署到 HTTPS 后可安装到手机或电脑桌面，并支持离线使用。

发布方法见 `DEPLOY.md`。

## 计算口径

- 所有尺寸均为纸箱外尺寸，单位 mm。
- 重量单位为 kg。
- 算法按三维柜内空间分层排布，并同时校验箱体越柜、重叠和载重上限。
- 当前版本未计入托盘、绑扎空间、柜门内凸、装卸间隙、重心分布及货物允许受压高度。
- 实际订柜前仍应结合货代柜型参数、包装变形量、托盘方案和现场装卸方式复核。
