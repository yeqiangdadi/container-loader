# 柜满载

面向外贸纸箱装柜的离线计算工具。直接打开 `index.html` 即可使用，不需要安装 Node.js、npm 或其他运行环境。

## 当前能力

- 支持 20GP、40GP、40HQ、45HQ 和自定义柜内尺寸。
- **混柜方案**：装柜方式可选「混柜：大柜 + 小柜」，设置大柜数量和小柜内尺寸；先装满组合柜，再依次装入后续柜。
- **自动组合上下层**：勾选后，标注「必须上层」的包装会自动与其下方同高托盘成对承托，形成组合单元；12 米级长管会自动在柜侧预留通道。
- 支持多项货物混装，录入纸箱长、宽、高、单件重量和数量。
- **批量导入货物清单**：三种方式，几十项货物无需逐条手填。
  - 「导入清单 → Excel / CSV 文件」：直接导入 `.xlsx / .xls / .csv / .txt`，自动识别表头（长、宽、高、数量、单件重量、货号、包装类型、允许叠放等中英文列名均可，含 `L-MM`、`GW-KGS` 这类带单位后缀的写法）、自动识别 UTF-8 / GBK（Excel 默认）编码和 mm / cm / m 单位；文件可以拖到页面任意位置；多工作表自动挑选格式最规整的一张；
  - 外贸装箱单格式（每行一箱、带 CBM 和毛重列）自动按「每行 = 1 箱」识别，同规格箱自动合并数量；也可在「数量列含义」里手动指定；
  - 「粘贴表格」：从 Excel 复制区域后直接粘贴，或点「读取剪贴板解析」一键读取；
  - 「AI 智能导入」：把不规范的货描、聊天记录、自然语言清单交给线上大模型（兼容智谱 GLM、DeepSeek、Kimi 等 OpenAI 接口格式）整理成结构化数据，API Key 只保存在本机浏览器；
  - 内嵌浏览器面板可能不弹系统文件选择窗，此时请用「粘贴表格 / AI 导入」，或用 Chrome / Edge 打开页面；
  - 「模板」下载标准 Excel 模板，「导出清单」把当前清单导出为 Excel，编辑后再导入。
- 叠放控制：柜型区「允许箱体叠放」总开关（关闭后全部单层摆放）；「默认顶部承重」决定未填写承重的包装能被压多重（默认 100 kg，设为 0 则未填承重即不可叠）；每项货物还可单独设置「允许上方叠放货物」和「顶部可承重」，单项填写的承重优先于默认值。
- 支持纸箱、木箱、捆包、托盘、圆柱/圆管和异形包装。
- 支持圆柱按直径、长度和轴向计算。
- 支持木箱底座高度，默认 100 mm，可选择录入总高是否包含底座。
- `20GP` 默认禁止装载 5.5 米以上长件；`40GP/40HQ/45HQ` 默认柜宽一列、柜长一位，并允许按设置的层数上下叠放。
- 支持可全向翻转、只可水平旋转、不可旋转。
- 叠放前校验底部支撑比例、顶部承重和支撑面积，未填写承重时不允许被压。
- 按柜内净空和最大载重计算，输出建议柜数、每柜装载件数、体积、重量和利用率，并提示哪些货物装不下及原因。
- 提供可旋转、缩放和切换正视图/俯视图的柜内摆放示意。
- 支持打印报告和导出 CSV 装柜清单。
- 支持复制方案链接，打开链接即可恢复柜型和货物数据。
- 部署到 HTTPS 后可安装到手机或电脑桌面，并支持离线使用。

发布方法见 `DEPLOY.md`。

## 计算口径

- 所有尺寸均为纸箱外尺寸，单位 mm。
- 重量单位为 kg。
- 算法采用最大空间法（MaxRects-3D / EB-AFIT 空间消去思路）：每放置一批同规格箱体，即从柜内所有相交的空闲空间中扣除该区域，持续维护最大残余空间，避免简单切割法留下的死空间；四种排布策略（最优贴合、体积优先、效率优先、高度优先）逐一尝试并择优。
- 有长管件时先排满长件通道，再由普通箱填补周边空间；长管件之间按柜载重计承重，允许多层码放。
- 叠放校验底部支撑比例、下方包装的顶部承重和支撑面积；已通过越柜、重叠、载重上限的全量校验。
- 当前版本未计入托盘、绑扎空间、柜门内凸、装卸间隙、重心分布及货物允许受压高度。
- 实际订柜前仍应结合货代柜型参数、包装变形量、托盘方案和现场装卸方式复核。
